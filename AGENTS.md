# AGENTS.md

## Project overview

This is a Vite application built with React 18 and TypeScript. It uses TanStack
Router for file-based routing, Material UI for components, and Firebase for
backend services.

## Common commands

- Install dependencies: `npm install`
- Start the development server: `npm run dev`
- Lint the project: `npm run lint`
- Generate the route tree: `npm run routes:generate`
- Create a production build: `npm run build`
- Start Firebase emulators: `npm run emulators`
- Stop Firebase emulators: `npm run emulators:down`

## Project structure

- `src/routes/`: TanStack Router route files
- `src/components/`: shared React components
- `src/firebase/`: Firebase configuration and integration
- `src/assets/`: application images and other bundled assets
- `scripts/`: repository maintenance and data-import scripts
- `public/`: static files served as-is

## Development guidelines

- Use TypeScript for application code and keep it compatible with strict mode.
- Prefer the `@/` alias for imports from `src`.
- Follow the existing code style and ESLint configuration.
- Reuse existing Material UI components and theme values before adding custom
  styling or new UI dependencies.
- Keep route-specific code in `src/routes` and reusable UI in `src/components`.
- Do not manually edit `src/routeTree.gen.ts`; it is generated by TanStack
  Router. Run `npm run routes:generate` after changing route files.
- Do not commit secrets, local environment values, build output, emulator state,
  or debug logs.
- Avoid unrelated edits and preserve changes already present in the worktree.

## Validation

For normal code changes, run:

1. `npm run lint`
2. `npm run build`

If a change depends on Firebase, also verify the relevant flow against the local
emulators when practical.
